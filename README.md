# Star Squadron — Arcade Draft

세로 화면용 1인 아케이드 슈팅 게임 초안입니다. 별도 서버나 외부 이미지·음원 없이 HTML Canvas와 JavaScript로 실행됩니다.

## 실행

`index.html`을 브라우저에서 열면 데스크톱 키보드로 시험할 수 있습니다. PWA 오프라인 설치는 HTTPS 또는 localhost에서 서비스 워커가 등록되어야 합니다.

## 조작

- 모바일: 왼쪽 붉은 조이스틱을 좌우로 움직여 기체 이동, 오른쪽 발사 버튼을 누르고 있으면 연속 발사
- 키보드: ←/→ 또는 A/D 이동, Space 발사, Enter 시작/재시작, M 음소거
- 상단 오른쪽 스피커 아이콘을 눌러 소리를 켜거나 끌 수 있습니다.

## 초안에 들어간 규칙

- 정렬된 적 편대와 소대별 급강하·집단 공격
- 일반 적 1회 피격, 편대장 다중 피격, 3스테이지마다 중간 보스
- 기본탄 → 쌍발탄 → 기관포 → 레이저 → 플라즈마 무기 강화 아이템
- 아이템은 떨어지는 동안 잡아야 하며, 놓치면 화면 아래로 사라짐
- 아이템을 놓치면 다음 스테이지에서 같은 강화 단계 운반 적이 다시 배정됨
- 최고 점수는 현재 기기에 저장됨

## 조정이 필요한 초안 값

스테이지별 적 속도, 공격 간격, 보스 내구도, 아이템 낙하 속도와 무기 피해량은 실제 플레이 후 조정해야 합니다. 무기 단계는 피격 시 유지되고 새 게임을 시작할 때 기본탄으로 초기화됩니다.
